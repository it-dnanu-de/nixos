### §0.4 Critical decisions (mandated by the task)

**D1 — DANE TLSA strategy: TLSA `3 1 1` (DANE-EE / SPKI / SHA-256) with fully automated sync.**
The task's option (b) — "pin the ACME key" — is impossible: lego (nixpkgs ACME) generates a **new private key at every renewal** and there is no key-reuse option. Option (a) as written ("update manually each rotation") violates the set-and-forget mandate. CA-pinning (`2 1 1` against an LE intermediate) is fragile: LE changes intermediates without notice. The robust $0 answer is (a) **automated**: a `cloudflare-tlsa-sync.service` computes the SPKI SHA-256 of `/var/lib/acme/mail.dnanu.de/cert.pem` and upserts `_25._tcp.mail.dnanu.de TLSA 3 1 1 <hex>` via the CF API. Triggers, in increasing sharpness: ACME `postRun` (fires only on renewal, runs *before* postfix reloads onto the new cert — by the time the new cert is served, DNS is already updated), a daily persistent timer (self-heal), and boot. Gap analysis: worst-case window between cert swap and DNS PATCH is seconds; TTL 120s bounds staleness; DANE-enforcing senders tempfail+retry, and TLS-RPT would surface any failure. Cost: $0. Human action: none, ever.
**Dependency:** DANE only becomes *active* once the zone's DS record is published at DENIC (Cloudflare signing is done; DS publication is an existing open 1%-manual item). Publishing TLSA now in the not-yet-DS'd zone is **safe** (unsigned zone → senders ignore TLSA) and means DANE goes live automatically the moment DS lands.

**D2 — RBL policy: rspamd-side only, stock lists, spamhaus explicitly disabled.**
No `reject_rbl_client` in postfix: our resolver path is AGH→quad9 (public), spamhaus returns `127.255.255.254 BLOCKED_OPENRESOLVER` there, and postfix's naive A-match could false-positive on block codes — dangerous and duplicated effort. rspamd 4.0.1 stock already queries a solid free set (mailspike, dnswl whitelist, spameatingmonkey, blocklist.de, virusfree, SURBL/URIBL/DBL) with proper return-code parsing and composite scoring. We add one local override: disable the `spamhaus` block (dead via public resolvers; skips useless lookups + log noise). barracuda needs registration, senderscore needs a paid account — out.

**D3 — MTA-STS HTTPS host: dedicated `mta-sts.dnanu.de` vhost on the existing 127.0.0.1:8080 nginx listener, fronted by the existing cloudflared tunnel.**
RFC 8461 mandates the policy at `https://mta-sts.<domain>/.well-known/mta-sts.txt` — serving from the apex vhost is **not** spec-compliant, so the "reuse dnanu.de vhost" option is out. Fewest moving parts that is compliant: new nginx vhost (static `pkgs.writeTextDir` root), one new cloudflared ingress line, one CNAME upsert (proxied — Cloudflare edge Universal SSL covers `*.dnanu.de`, so policy fetchers see a valid cert). No ACLs — the policy must be world-fetchable.

**D4 — postfix restriction set (strict but FP-safe):**
```
smtpd_helo_required = yes
smtpd_helo_restrictions      = permit_mynetworks, reject_non_fqdn_helo_hostname, reject_invalid_helo_hostname
smtpd_sender_restrictions   += reject_non_fqdn_sender, reject_unknown_sender_domain
smtpd_recipient_restrictions+= reject_non_fqdn_recipient, reject_unknown_recipient_domain, reject_unauth_pipelining
```
All are RFC-conformance checks; every legit MTA (Google, Microsoft, Proton, Resend) passes them. `reject_unknown_sender_domain` 450s on transient DNS errors (sender retries) and 550s on NXDOMAIN (correct). Deliberately **rejected**: `reject_unknown_helo_hostname` (too many legit-but-sloppy senders), `strict_rfc821_envelopes` (breaks real clients), sender callout verification (abuse vector), postscreen (greylisting+rspamd already cover it), `rewriteMessageId` (client-compat warning in SNM docs). Greylisting stays untouched (it works).

**D5 — outbound TLS: static `verify` policy for the Resend relay, first in the policy map.**
Remove `smtp_tls_security_level = lib.mkForce "encrypt"`; add `mapFiles."tls_policy"` with `[smtp.resend.com]:465 verify` + `smtp.resend.com verify`, prepended via `lib.mkBefore` so it beats the tlspol socketmap. Effect: the money path gets mandatory TLS **with CA + hostname verification** (upgrade from today's unverified encryption), tlspol keeps handling DANE/MTA-STS for any future direct-MX destination, global level falls back to SNM/tlspol's `dane` (used rarely; harmless). Rollback if Resend's cert ever fails verification: flip `verify`→`encrypt` in the map (one word).

**D6 — monitoring channel: alert via Resend HTTPS API, not via local postfix.**
A queue-stuck alert sent through the stuck queue is silent. The watchdog curls `api.resend.com/emails` directly (existing `resend_api_key` sops secret, free tier, independent of the failure domain), rate-limited (6 h cooldown state file), to `hey@dnanu.de`. Checks: postfix/dovecot2/rspamd active + queue age >30 min or >2 queued. Silence = healthy.

**D7 — DMARC path:** keep `p=quarantine` now; human flips to `p=reject` (one line in `cloudflare-dns.nix`) after a 30-day clean DMARC-report window. SPF stays `v=spf1 -all` (nothing sends envelope `@dnanu.de`; Resend uses `send.dnanu.de`, confirmed live). No `ruf` (forensic reports leak content; negligible sender support).

```nix

    mapFiles."tls_policy" = pkgs.writeText "tls_policy" ''
      [smtp.resend.com]:465 verify
      smtp.resend.com verify
    '';

    settings.main = {
      # (keep existing relayhost/sasl/wrappermode lines)
      # REMOVED: smtp_tls_security_level = lib.mkForce "encrypt";
      smtp_tls_policy_maps = lib.mkBefore [ "hash:/var/lib/postfix/conf/tls_policy" ];

      smtpd_helo_required = "yes";
      smtpd_helo_restrictions = [
        "permit_mynetworks"
        "reject_non_fqdn_helo_hostname"
        "reject_invalid_helo_hostname"
      ];
      smtpd_sender_restrictions = lib.mkAfter [
        "reject_non_fqdn_sender"
        "reject_unknown_sender_domain"
      ];
      smtpd_recipient_restrictions = lib.mkAfter [
        "reject_non_fqdn_recipient"
        "reject_unknown_recipient_domain"
        "reject_unauth_pipelining"
      ];
    };
```

Notes for the builder: `lib.mkAfter` appends to SNM's existing lists (do not replace them). `lib.mkBefore` prepends to tlspol's `smtp_tls_policy_maps` list — final value renders as `hash:/var/lib/postfix/conf/tls_policy, socketmap:unix:/run/postfix-tlspol/tlspol.sock:QUERYwithTLSRPT`. Removing the `mkForce "encrypt"` line lets the global level become `dane` (SNM + tlspol both set it, equal values merge cleanly). `postfix-setup.service` postmaps the new `tls_policy` map automatically (same mechanism as the existing `sasl_passwd` map).

What tlsrpt/dmarcReporting change operationally: `tlsrpt-collectd` + `tlsrpt-reportd` units appear; postfix logs TLS per-destination to the collectd socket; reportd mails daily aggregate reports to domains publishing `_smtp._tls` (sender `noreply-tlsrpt@dnanu.de`, via sendmail → Resend relay). `rspamd-dmarc-reporter` timer sends DMARC aggregates (sender `noreply-dmarc@dnanu.de`). Both sender addresses intentionally don't exist as mailboxes; double-bounces land at `postmaster@` → `admin@`. No new secrets.

### §3.3 DANE TLSA (D1) — new unit in `modules/services/cloudflare-dns.nix`

```nix
  systemd.services.cloudflare-tlsa-sync = {
    description = "Cloudflare TLSA (DANE) record sync for mail.dnanu.de";
    after = [ "network-online.target" "nss-lookup.target" ];
    wants = [ "network-online.target" ];
    wantedBy = [ "multi-user.target" ];
    path = with pkgs; [ curl jq coreutils openssl ];
    serviceConfig = {
      Type = "oneshot";
      Restart = "on-failure";
      RestartSec = "60s";
      StartLimitBurst = 5;
      LoadCredential = "cloudflare_api_token:${cfToken}";
    };
    script = ''
      set -euo pipefail
      CERT="/var/lib/acme/${settings.domains.mail}/cert.pem"
      [ -f "$CERT" ] || { echo "no cert yet"; exit 0; }
      HASH=$(openssl x509 -in "$CERT" -pubkey -noout \
             | openssl pkey -pubin -outform DER \
             | openssl dgst -sha256 -r | cut -d' ' -f1)
      CONTENT="3 1 1 $HASH"
      NAME="_25._tcp.${settings.domains.mail}"
      TOKEN="$(cat "$CREDENTIALS_DIRECTORY/cloudflare_api_token")"
      API="https://api.cloudflare.com/client/v4/zones"
      CURL() { curl -sS --fail --retry 8 --retry-delay 5 --retry-all-errors --connect-timeout 10 \
                 -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" "$@"; }
      ZONE=$(CURL "$API?name=${settings.domains.public}" | jq -r '.result[0].id')
      REC=$(CURL "$API/$ZONE/dns_records?type=TLSA&name=$NAME")
      ID=$(echo "$REC" | jq -r '.result[0].id // empty')
      CUR=$(echo "$REC" | jq -r '.result[0].content // empty')
      if [ "$CUR" = "$CONTENT" ]; then echo "TLSA up to date"; exit 0; fi
      BODY=$(jq -nc --arg n "$NAME" --arg c "$CONTENT" '{type:"TLSA",name:$n,content:$c,ttl:120}')
      if [ -n "$ID" ]; then
        CURL -X PATCH "$API/$ZONE/dns_records/$ID" -d "$BODY" > /dev/null
        echo "TLSA updated: $CONTENT"
      else
        CURL -X POST "$API/$ZONE/dns_records" -d "$BODY" > /dev/null
        echo "TLSA created: $CONTENT"
      fi
    '';
  };

  systemd.timers.cloudflare-tlsa-sync = {
    wantedBy = [ "timers.target" ];
    timerConfig = { OnCalendar = "daily"; Persistent = true; RandomizedDelaySec = "1h"; };
  };
```

ACME hook in `modules/networking/acme.nix` (add `pkgs` to the module args; inside `certs."mail.dnanu.de"`):

## §4 `cloudflare-dkim-sync.service` fix — `modules/services/cloudflare-dns.nix`

**Diagnosis (all confirmed live, §0.3):**
1. Boot-time exit 6: unit ordered after `network-online.target` + nonexistent `dkim-setup.service`, but DNS (AGH on :53) isn't up when it runs → curl can't resolve `api.cloudflare.com` → exit 6, no retry, dead until manual start.
2. Parser bug: `sed 's/.*( \(.*\) ).*/\1/'` expects `space)` before `)`; rspamadm output has `")` → no match → raw zone fragment published as the TXT value.
3. Delete-then-POST creates a record gap; no content comparison; no `set -e` so CF HTTP errors passed silently.

**Fix — replace the whole unit:**

```nix
  systemd.services.cloudflare-dkim-sync = {
    description = "Cloudflare DKIM TXT record sync";
    # rspamd.service generates the keypair in ExecStartPre — order after it.
    # (dkim-setup.service no longer exists in SNM 26.05.)
    after = [ "rspamd.service" "network-online.target" "nss-lookup.target" ];
    wants = [ "network-online.target" ];
    wantedBy = [ "multi-user.target" ];
    path = with pkgs; [ curl jq coreutils gnugrep ];
    serviceConfig = {
      Type = "oneshot";
      Restart = "on-failure";   # survives boot-time DNS races
      RestartSec = "30s";
      StartLimitBurst = 5;
      LoadCredential = "cloudflare_api_token:${cfToken}";
    };
    script = ''
      set -euo pipefail
      DKIM_FILE="${config.mailserver.dkim.keyDirectory}/${settings.domains.public}.${config.mailserver.dkim.defaults.selector}.txt"
      [ -f "$DKIM_FILE" ] || { echo "no dkim key yet"; exit 0; }
      # Extract all quoted fragments and join them (format-agnostic — no paren parsing)
      VALUE=$(grep -o '"[^"]*"' "$DKIM_FILE" | tr -d '"\n')
      [ -n "$VALUE" ] || { echo "dkim parse failed"; exit 1; }
      TOKEN="$(cat "$CREDENTIALS_DIRECTORY/cloudflare_api_token")"
      API="https://api.cloudflare.com/client/v4/zones"
      CURL() { curl -sS --fail --retry 8 --retry-delay 5 --retry-all-errors --connect-timeout 10 \
                 -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" "$@"; }
      ZONE=$(CURL "$API?name=${settings.domains.public}" | jq -r '.result[0].id')
      REC=$(CURL "$API/$ZONE/dns_records?type=TXT&name=mail._domainkey.${settings.domains.public}")
      ID=$(echo "$REC" | jq -r '.result[0].id // empty')
      CUR=$(echo "$REC" | jq -r '.result[0].content // empty')
      if [ "$CUR" = "$VALUE" ]; then echo "DKIM up to date"; exit 0; fi
      BODY=$(jq -nc --arg c "$VALUE" '{type:"TXT",name:"mail._domainkey",content:$c,ttl:120}')
      if [ -n "$ID" ]; then
        CURL -X PATCH "$API/$ZONE/dns_records/$ID" -d "$BODY" > /dev/null   # in-place, no gap
        echo "DKIM updated"
      else
        CURL -X POST "$API/$ZONE/dns_records" -d "$BODY" > /dev/null
        echo "DKIM created"
      fi
    '';
  };
```

Key properties: idempotent (no-op when content matches), self-healing (`--retry-all-errors` + systemd `Restart=on-failure`), gapless (PATCH in place), and safe JSON (`jq -nc`). Note: CF may normalize TXT quoting in API responses; if a cosmetic mismatch makes every run PATCH, that's harmless (same value rewritten).

## §5 Monitoring ($0, set-and-forget)

New in `modules/services/mail.nix`:

```nix
  # Queue/service watchdog — alerts via Resend HTTPS API (independent of local
  # postfix, so it works even when the queue is the problem). $0: free tier,
  # existing sops key. Rate-limited: one alert per 6h.
  systemd.services.mail-queue-watch = {
    description = "Mail queue + service health watchdog";
    serviceConfig = {
      Type = "oneshot";
      StateDirectory = "mail-alert";
      LoadCredential = "resend_api_key:${config.sops.secrets.resend_api_key.path}";
      NoNewPrivileges = true;
      PrivateTmp = true;
    };
    path = with pkgs; [ curl jq coreutils gawk ];
    script = ''
      set -uo pipefail
      STATE="$STATE_DIRECTORY/last-sent"
      now=$(date +%s)
      last=$(cat "$STATE" 2>/dev/null || echo 0)
      problems=""

      for u in postfix dovecot2 rspamd; do
        systemctl is-active --quiet "$u" || problems="$problems $u-down"
      done

      # queue size + oldest age via postqueue JSON
      qjson=$(postqueue -j 2>/dev/null || true)
      qcount=$(echo "$qjson" | jq -s 'length')
      oldest=$(echo "$qjson" | jq -s 'map(.arrival_time // empty) | min // 0')
      [ "$qcount" -gt 2 ] && problems="$problems queue-size=$qcount"
      if [ "$oldest" != "0" ] && [ $((now - oldest)) -gt 1800 ]; then
        problems="$problems queue-oldest=$(( (now - oldest) / 60 ))min"
      fi

      if [ -n "$problems" ] && [ $((now - last)) -gt 21600 ]; then
        body="homelab mail watchdog:$problems"
        if curl -sS --fail -X POST "https://api.resend.com/emails" \
            -H "Authorization: Bearer $(cat "$CREDENTIALS_DIRECTORY/resend_api_key")" \
            -H "Content-Type: application/json" \
            -d "$(jq -nc --arg b "$body" '{from:"alert@dnanu.de",to:["hey@dnanu.de"],subject:"[homelab] mail watchdog",text:$b}')" > /dev/null; then
          echo "$now" > "$STATE"
          echo "alert sent:$problems"
        else
          echo "alert FAILED:$problems"; exit 1
        fi
      else
        echo "ok$problems"
      fi
    '';
  };

  systemd.timers.mail-queue-watch = {
    wantedBy = [ "timers.target" ];
    timerConfig = { OnCalendar = "*:0/15"; Persistent = true; };
  };
```

Report consumption: TLS-RPT + DMARC aggregate reports arrive as mail at `admin@dnanu.de` (gzip JSON / zip XML) — human eyeballs them occasionally; no parser infra for a single-user box. Our own outgoing reports are handled by `tlsrpt-reportd` + `rspamd-dmarc-reporter` (both declarative, timers included). Beszel later adds pretty graphs but is not required.

## §9 Risks & rollback (per phase)

| Phase | Risk | Mitigation / rollback |
|---|---|---|
| A (DNS/DKIM/MTA-STS) | Bad DKIM PATCH breaks signing verification | Compare-before-write; value comes from the on-disk key rspamd actually uses → they match by construction. Rollback: `git revert`, records stay (delete manually if ever needed). |
| A | mta-sts vhost unreachable → STS fetch failures (invisible until enforce matters) | §6.4 external curl check gates the phase. cloudflared/nginx unchanged for other hosts. |
| B | `verify` policy breaks outbound to Resend (cert chain/hostname issue) | Immediate signal: watchdog alert + non-empty mailq + `journalctl -u postfix` TLS errors. Rollback: one word `verify`→`encrypt` in `tls_policy`, rebuild. Pre-checked: CAfile already live, Resend cert SAN = `smtp.resend.com`. |
| B | New restrictions false-positive a legit sender | Chosen checks are RFC-conformance-only; a rejected sender gets a clean 5xx bounce (visible, not silent). Rollback: drop the three restriction lines. Greylisting untouched. |
| B | reject=12 drops borderline-legit bulk mail | rspamd keeps reject-score mail out by design; watch first DMARC reports + ask human to report missing newsletters. Rollback: delete `actions.conf` local (stock 15). |
| C | TLSA/cert mismatch window at renewal | postRun fires pre-reload; TTL 120s; senders tempfail+retry; daily timer + boot run as backstops. Worst case until DS is published: **zero** (zone unsigned → TLSA ignored). |
| D | Watchdog false alerts / Resend API down | 6h rate-limit caps noise (≤4 mails/day, free tier 100/day). API down → unit fails, visible in `systemctl --failed`; no mail impact. |
| All | DNSSEC caveat (from §3.7): once DS is published, never disable CF signing and never let tlsa-sync rot — both are now automated | tlsa-sync has 3 independent triggers; watchdog covers postfix; DS publication is a human checklist item with the activation note. |

**Blast-radius summary:** inbound mail path changes are additive restrictions + DNS records; outbound changes one policy word; the only service-restart-heavy phase is B (postfix reload). Every phase is independently revertible with `git revert` + rebuild; DNS records converge back via the sync scripts.
